アンタルヤ空港に到着したら：着陸後の流れ

着陸から車のドアまで。ターミナル、入国審査、合流場所、そしてフライトが遅れたときに何が起きるか。

更新日 2026-09-16·読了 約5分

アンタルヤ空港は年間三千万人超を扱い、そのほとんどが夏の限られた期間に集中します。流れを先に把握しておけば、混雑したターミナルも二十分程度の手続きになります。

どのターミナルに到着するか

AYT にはターミナルが三つあります。定期国際線の多くは第1ターミナルか第2ターミナルを使い、チャーター便や季節運航便は通常第2ターミナルで扱われます。国内線ターミナルはイスタンブール、アンカラ、イズミルからの便に対応します。これをご自身で判断する必要はありません。便名から当社が特定し、ドライバーを正しい到着ロビーへ向かわせます。

入国審査と手荷物

日本国籍を含め多くの国籍の方は短期滞在ならビザなしでトルコに入国できますが、ご自身のパスポートに適用される条件は出発前に確認してください。ハイシーズンは着陸から荷物を持って出るまで20〜45分をみてください。7〜8月以外はそれより短くなります。最も変動が大きいのは手荷物の受け取りで、だからこそ「約束された出迎え時刻」より「待機時間の幅」のほうが重要になります。

ドライバーとの合流場所

  • 手荷物を受け取り、到着ロビーへお進みください。
  • ミート＆グリートエリア J / 777 へ向かってください。
  • 空港スタッフがご予約を確認し、ドライバーまでご案内します。
  • ドライバーが近くの駐車場の車両まで荷物をお運びします。

五十人の中から名前のプレートを探す必要はありません。スタッフは決まった場所に立ち、ご予約番号を持っているため、朝6時でも深夜2時でも引き渡しの流れは同じです。

フライトが遅れたときは

当社が追跡するのは、予約時に入力された時刻ではなくフライトそのものです。二時間遅れて着陸すれば出迎えも二時間後ろにずれ、料金は変わりません。実際の着陸時刻からの最初の90分は無料で含まれており、入国審査の長い列や遅れた手荷物を十分にカバーします。

ご出発前に

当日を楽にする要素は二つです。到着時刻だけでなく便名をお知らせいただくこと、そしてチャイルドシートの数を予約時にお伝えいただくこと。どちらも無料ですが、どちらも深夜1時の到着ロビーで手配するのははるかに困難です。

よくある質問

アンタルヤ空港では、どこでドライバーと合流しますか。

手荷物を受け取ったあと、到着ロビーのミート＆グリートエリア J / 777 です。スタッフがご予約を確認し、ドライバーまでご案内します。

ドライバーはどのくらい待ちますか。

実際の着陸時刻からの最初の90分は無料で含まれ、フライトが遅延した場合はこの時間帯が自動的に後ろへずれます。

ターミナルを出るまでどのくらいかかりますか。

入国審査と手荷物の状況にもよりますが、着陸から通常20〜45分です。7月と8月が最も長くかかります。

便名は必ず伝える必要がありますか。

はい。便名があることで実際の着陸時刻を追跡でき、ドライバーを正しいターミナルへ向かわせられます。
