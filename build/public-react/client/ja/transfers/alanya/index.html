よくある質問

アンタルヤ空港からアランヤまでの送迎はどのくらいかかりますか？

通常の交通状況で所要時間は約110〜130分です。

アランヤへの固定送迎料金はいくらですか？

Mercedes Vitoの料金は1台あたり€98からです。確定合計金額は予約時に表示されます。

フライトが遅延した場合はどうなりますか？

私たちはお客様のフライトをリアルタイムで追跡し、追加料金なしでお迎え時間を調整します。

運転手は空港でどのくらい待ちますか？

着陸後の最初の90分は無料に含まれており、フライトが遅延した場合は自動的に時間枠が移動します。

送迎料金の支払い方法は？

旅程開始時に運転手へ現金でお支払いください。予約時の固定料金、1台あたりの金額です。
